# build-work-context

The flagship ClinPharm PMx Skills Skill for creating and refreshing portable professional
and project context.

## Use it when

- a pharma professional wants an AI to interview them;
- a user needs reusable ChatGPT, Claude, Copilot, or project context;
- an existing work-context file needs updating;
- permitted project files need to become a focused project capsule; or
- a professional context and project capsule need to be exported as one working
  pack.

## Outputs

- `My-Pharma-Work-Context.md` and optionally `.docx`
- `Project-Context-<project>.md`
- `AI-Working-Pack-<project>.md` and optionally `.docx`
- `Context-Change-Summary.md`

## Safety

The skill begins by establishing the current environment and data boundary. It
does not provide patient-specific clinical decisions, send external content, or
replace qualified scientific and regulatory review.

See [`SKILL.md`](SKILL.md) for the workflow.
