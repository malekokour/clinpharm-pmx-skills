# CTD 2.7.3.4 Exposure-Safety Review

Owns the job-model row **CTD 2.7.3.4 and 2.7.4 exposure-safety**. Split from `review-exposure-safety-margins` under PS-D030.

The defect it exists to catch: a negative exposure-safety statement resting on an analysis with too few events to have detected anything. In a submission that reads exactly like evidence of no effect.
