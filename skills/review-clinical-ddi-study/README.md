# Clinical DDI Study Review

Owns the job-model row **Clinical DDI studies**. Split from `review-ddi-evidence` under PS-D030 so one package owns one row.

Reviews clinical interaction study reports for design adequacy, result integrity and coverage against in-vitro triggers. It separates inconclusive studies from negative ones, and does not judge whether an exposure change matters clinically.
