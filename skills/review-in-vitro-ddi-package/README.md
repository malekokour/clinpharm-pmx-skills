# In-Vitro DDI Package Review

Owns the job-model row **In-vitro DDI package**. Split from `review-ddi-evidence` under PS-D030 so one package owns one row.

Reviews an in-vitro interaction package for completeness and decision-readiness. It does not judge clinical significance, does not decide whether a clinical study is required, and does not supply a parameter the package does not carry.

See [`SKILL.md`](SKILL.md).
