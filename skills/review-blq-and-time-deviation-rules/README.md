# BLQ and Time-Deviation Rules Review

Owns the job-model row **BLQ, actual-versus-nominal times, exclusion rules**. Split from `verify-nca-outputs` under PS-D030.

The defect it exists to catch: an exclusion rule that requires judgment about whether a value is implausible. That is an analysis decision wearing the clothes of a data rule, and it gets applied by someone who has already seen the concentration.
