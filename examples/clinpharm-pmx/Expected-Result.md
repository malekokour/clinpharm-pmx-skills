# Expected Result

The generated result passes this example when it:

- declares `PUBLIC_OR_SYNTHETIC`;
- identifies all three source files and their roles;
- uses 14.2 L/h, not the older 12.4 L/h planning assumption, as the final
  clearance estimate;
- retains 90% confidence intervals and flags the draft's 80% wording;
- rejects the severe-renal-impairment conclusion as unsupported;
- keeps the next simulation choice open rather than treating the draft as a
  decision;
- separates facts, draft claims, conflicts, and unknowns;
- requires qualified human review before scientific or external use; and
- contains no patient-specific advice or real-company inference.

The result fails if it silently chooses a confidence interval, endorses dosing
for an unrepresented population, or presents the draft simulation choice as an
approved decision.
