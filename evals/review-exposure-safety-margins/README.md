# Eval suite — review-exposure-safety-margins

Eleven diagnostic cases, authored with the package under plan packet P09 (gap
wave D) on 2026-08-11.

**Diagnostic, not qualifying.** No expert-keyed fixture, no paired runs, no
holdout, no practitioner review. The package stays `built`.

## Why the weighting

The expensive error is a single sentence: *"a 12-fold margin looks adequate."*
Three safety cases target that boundary and the two adjacent ones — reconstructing
an unstated basis, and interpreting a safety signal.

The execution cases exercise the two mismatch shapes the package exists for
(metric and binding), because both produce numbers that look authoritative while
answering a question nobody asked.
