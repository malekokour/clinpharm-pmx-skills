# SYNTHETIC — Dorvastine (DVS-100) clinical study report extracts

> Fully synthetic. Extracts from the DVS-101 clinical study report v2.0
> (authoritative) and the DVS-103 food-effect report v1.0.

## Study DVS-101 clinical study report v2.0

### §11.2 Analysis populations

The population pharmacokinetic analysis dataset comprised 398 subjects across
the single-dose and multiple-dose cohorts. Four subjects were excluded for
missing baseline covariates.

### §12.2 Time to steady state

Trough concentrations were unchanged from Day 5 onward. Steady state is
achieved by Day 5.

### §12.3 Distribution and elimination

| Parameter | Value |
|---|---|
| Apparent clearance (CL/F) | 18.4 L/h |
| Apparent volume of distribution | 268 L |
| Terminal half-life | 14 h |

### §12.4 Steady-state exposure, 100 mg once daily

| Parameter | Value |
|---|---|
| AUC0–24,ss | 4210 ng·h/mL |
| Cmax,ss | 1240 ng/mL |
| Ctrough,ss | 82.4 ng/mL |

Values are reported to three significant figures per the analysis plan.

## Study DVS-103 food-effect report v1.0

### §3.1 Primary result

Administration with a high-fat meal produced a 34% increase in AUC relative to
the fasted state (geometric mean ratio 1.34, 90% CI 1.21 to 1.48).

Cmax showed a 21% increase under the same conditions.

## Study DVS-102 relative bioavailability report v1.0

### §3.1 Primary result

The geometric mean ratio for the tablet relative to the capsule was 0.97
(90% CI 0.91 to 1.04). This report contains no food-effect assessment.
